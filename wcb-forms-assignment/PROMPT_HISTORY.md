# AI Prompt History

**AI Tool Used:** Claude AI

Claude was used during the development of this assignment for understanding the requirements, analysing the provided PDFs, generating and improving HTML/CSS/JavaScript code, debugging.

### Main Prompts Used

1. **Assignment Overview**
   Asked Claude to explain the assignment requirements and list all tasks, deliverables, and submission requirements.

2. **PDF Analysis**
   Asked Claude to analyse the provided PDFs and identify the layout, header, footer, images, tables, page numbers, static elements, and fields that should be dynamic.

3. **HTML/CSS/JavaScript Implementation**
   Asked Claude to help recreate the PDFs using HTML, CSS, and JavaScript while maintaining a similar visual layout.

4. **Dynamic Data**
   Asked Claude to make the forms and tables dynamic so that different datasets and different numbers of records can be displayed without manually changing the HTML.

5. **Debugging and Improvements**
   Asked Claude to identify and fix HTML, CSS, JavaScript, layout, and dynamic behaviour issues and improve the similarity to the original PDFs.

### AI Usage Declaration

Claude was used as an assistance tool throughout the development process. The final implementation was reviewed, tested, and modified before submission.
